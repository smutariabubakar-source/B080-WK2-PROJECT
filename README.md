NETWORKWALKS RECONNAISSANCE PROJECTS

OVERVIEW
This repository contains three cybersecurity reconnaissance projects completed as part of my Networkwalks practical training.

The projects demonstrate the use of publicly available information and security tools to identify domain information web technologies, and web application firewall technology.

PROJECTS
1  WHOIS
WHOIS was used to collect publicly available domain registration information.

Key Information Identified:

.  Domain ID
.  Registrar 
.  Creation Date
.  Updated Date
.  Registrar Expiry Date
.  Name Server
.  Other publicly available domain information

Security Awareness:
Publicly available domain and DNS information can assist reconnaissance.  Organizations should protect registrar accounts, use MFA, monitor domain changes, and minimize unnecessary exposure of sensitive information.

2  WhatWeb

WhatWeb was used to identify technologies and characteristics and characteristics associated with the target website.

Key Observations
.  HTTP 301 Moved Permanently
.  IP address
.  HTML
.  WordPress
.  Google Tag Manager
.  Country information
.  Frame detected web technologies

Security Awareness:
Technology fingerprinting can reveal information about a website's technology stack.  Organizations should keep web platforms and components updated, remove unnecessary components, and review externally exposed technologies.

3  WAFW00F
WAFW00F was used to identify the Web Application Firewall protecting the target website.

Finding:
. NodSecurity (Spider Labs) WAF

Security Awareness:
A WAF provides an additional layer of web application protection, but it should not be considered the only security control.  Application, servers, CMS platforms, and other components must also be securely configured and maintained.

Ethical and Security Considerations:

These activities were performed as part of authorized cybersecurity learning and reconnaissance exercises.  The tools were used to observe publicly available information and identify technologies without attempting to bypass security controls or gain unauthorized access.

Learning Outcome

These projects provided practical experience with:
  Domain reconnaissance
  Web technology identification
  WAF identification
  Security Awareness
  Security documentation
  Ethical cybersecurity practices
